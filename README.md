# TecnoSerprofes

Este proyecto se ha creado como una práctica de clase sobre desarrollo y optimización SEO de una web estática.

TecnoSerprofes es una empresa ficticia. La dirección, el teléfono y el correo que aparecen en el sitio son datos de ejemplo para esta actividad y no corresponden a un negocio real.

La práctica incluye páginas HTML semánticas, metadatos SEO, diseño adaptable, una imagen WebP y una versión JPEG recortada a 1200x630 para Open Graph, una página 404, `robots.txt` y `sitemap.xml`.
